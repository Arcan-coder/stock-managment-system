# stock-managment-system

Automated Inventory & Supplier Management System is a web-based MVP that helps businesses manage products, suppliers, and stock levels while automatically generating and emailing daily, weekly, and monthly reports through a mobile-friendly dashboard with admin and staff roles.

## Additional prototype: Marks Performance MVP

This repository now also contains a standalone marks-tracking MVP in `marks_performance_mvp/` for students to:
- input marks by subject and assessment type,
- compare averages vs targets,
- detect trends and weak areas,
- generate a weekly improvement tracker.

See `marks_performance_mvp/README.md` for usage.
